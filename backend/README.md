# МГТС · веб-дашборд

Из корня проекта установите зависимости и запустите локальный сервер.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt -r frontend/requirements.txt
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Для существующего окружения пропустите создание `.venv`. Откройте
[дашборд](http://127.0.0.1:8000) или [описание API](http://127.0.0.1:8000/docs).
Для запуска только новой версии достаточно `backend/requirements.txt`.

FastAPI отдаёт интерфейс из `frontend/web` и JSON из `/api`. Исходные
Excel-файлы остаются в `data`. Streamlit можно запустить отдельно по
[его инструкции](../frontend/README.md).

## ИИ-выводы

Настройки провайдера берутся из переменных окружения и `llm/.env`.
Названия параметров приведены в `llm/.env.example`. Ключи нужны только
для ИИ-выводов. При первом открытии обзора или конкретного профиля запрос
запускается автоматически, если для этих данных ещё нет вывода. После сбоя
можно повторить запрос, а готовый вывод — обновить. Для официальных хостов
GigaChat приложение использует корневой сертификат из `llm/gigachat-root-ca.crt`.
Сертификат загружен по официальной ссылке из [документации GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates).
При собственной конфигурации можно указать путь к другому PEM-файлу в `LLM_CA_FILE`.

Запрос по программе передаёт провайдеру сводные оценки. Запрос по стажёру
также использует помесячные ответы, оценки и комментарии наставников.
Выводы кэшируются в памяти локального процесса до перезапуска. После
изменения Excel или настроек модели прежний вывод больше не выдаётся за
актуальный для нового набора данных.

## Цветовые акценты

Для балльных показателей низкая оценка — ниже 60% от максимума, средняя —
от 60% до 80%, высокая — от 80%. Это пороги визуального отображения.
Оценки готовности к найму на кольцевой диаграмме сгруппированы по тем же порогам.

## Проверки

```bash
.venv/bin/python -m pytest backend/tests frontend/tests -q
node --check frontend/web/assets/dashboard.js
```

Тесты API выполняются без реальных запросов к модели.
