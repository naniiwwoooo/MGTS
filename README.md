# МГТС · Дашборд стажёрской программы

Дашборд показывает результаты опросов стажёров и наставников. В обзоре видна динамика программы, в профиле — оценки и отзывы по конкретному стажёру. FastAPI запускает и сервер, и веб-интерфейс. В панели «Спросить по данным» можно уточнить оценку или открыть исходные значения по ссылке из ответа.

## Запуск после скачивания с GitHub

Понадобится Python 3.11 или новее. Если скачали ZIP, распакуйте его и откройте терминал в папке, где находятся `backend`, `frontend` и `data`. Если скачиваете через Git, выполните:

```bash
git clone https://github.com/naniiwwoooo/MGTS.git
cd MGTS
```

### macOS и Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

### Windows PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Откройте [дашборд](http://127.0.0.1:8000). Для остановки сервера нажмите `Ctrl+C` в терминале. Если порт занят, замените `8000` на `8001` и откройте адрес с новым портом.

История загружается из `data/interns.xlsx` (лист «Ответы стажеров») и `data/mentors.xlsx` (лист «Оценки наставников»). Для таблиц и графиков достаточно этих файлов и установленных зависимостей.

## Как включить выводы GigaChat-2

1. Получите ключ авторизации GigaChat API в личном кабинете провайдера.
2. Скопируйте [llm/.env.example](llm/.env.example) в `llm/.env`. В новом файле задайте свой ключ в `LLM_API_KEY`, оставьте `LLM_PROVIDER=GigaChat` и `LLM_MODEL=GigaChat-2`. Значение `LLM_SCOPE` должно соответствовать типу вашего подключения.
3. Перезапустите сервер. Вывод появится автоматически при открытии обзора или профиля.

Файл `llm/.env` содержит ключ доступа и предназначен для локального использования. В веб-дашборде провайдер получает рассчитанные оценки, число ответов и обозначения сигналов, найденных локально. Тексты комментариев и ID стажёров остаются на локальном сервере.

## Обновление данных

Дашборд перечитывает обновлённые книги без перезапуска. При стандартном запуске FastAPI также читает [ответы стажёров](https://docs.google.com/spreadsheets/d/1NYC30wiV42Tq459fBLIxOv1fyZJduEqltJARKC8kNM0/edit#gid=720609798) и [оценки наставников](https://docs.google.com/spreadsheets/d/1FQ6aoRbP-ZMkTf80mxnMhV28TnbSBluBdcWkxV1idW4/edit#gid=1575164264) из Google Sheets. Первая анкета стажёра с новым ID создаёт профиль. Ответы стажёра и наставников сопоставляются по ID стажёра и одному из шести контрольных месяцев. Общий обзор охватывает всех стажёров.
